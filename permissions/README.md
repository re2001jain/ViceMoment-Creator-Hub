# Permission evidence (local only)

Keep permission proof on your own computer in this folder. Do not commit private emails, names, addresses, or screenshots to the public GitHub repository.

For each source video:
1. Get written permission from the actual rights holder (not merely the uploader if they do not own all elements).
2. Ask for explicit permission to edit, create Shorts/derivatives, publish on YouTube, and use commercially/monetize.
3. Clarify territory, duration, attribution requirements, and whether music/game audio is covered.
4. Save the permission message or licence as a text/PDF/image file in this local folder.
5. Add the exact source filename and evidence path to your local `rights.csv`.

Permission to use video footage does not automatically clear music, third-party overlays, logos, or other embedded material. YouTube says permission does not guarantee avoiding claims, and reused-content monetization rules are separate from copyright.
