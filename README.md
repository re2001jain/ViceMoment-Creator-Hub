# ViceMoment Creator Hub

A beginner-friendly workspace for planning and tracking GTA V / GTA Online YouTube Shorts.

## Version 1.0: Idea tracker

Start with [ideas.csv](ideas.csv). Open it in GitHub, Google Sheets, or Excel.

### Workflow
1. Add a new idea and a link to the source clip or your own gameplay.
2. Write a short hook for the first 1–2 seconds.
3. Score the idea from 1–10 using the guide below.
4. Check that you have permission to use the footage, or use your own gameplay. Add original commentary, editing, and meaningful creative value; a simple repost may not qualify for monetization.
5. Change the status as you work: New → Researching → Selected → Editing → Published.
6. After publishing, enter views and likes at a consistent checkpoint (for example, 48 hours).

## Idea score (1–10)
- 1–3: unclear moment or weak opening
- 4–6: understandable, but familiar or slow
- 7–8: instantly clear, surprising, funny, or satisfying
- 9–10: unusually strong hook plus a memorable payoff

This is a planning score, not a prediction or guarantee of virality.

## Status values
New, Researching, Selected, Editing, Published, Rejected

## Important
- Ideas in the starter tracker are creative prompts, not verified viral trends.
- Do not store passwords, API keys, private analytics, or personal information in this public repository.
