## Short concept
A high-risk GTA stunt: can the helicopter touch down on a moving truck without falling off?

## Recommended format
- Canvas: vertical 9:16
- Export: 1080 × 1920, 30 or 60 fps to match the source recording
- Target length: 18–24 seconds
- Style: fast, suspenseful, satisfying payoff
- Keep the landing and the truck visible; do not crop out the key action.

## Edit structure (action-based, not fixed source timestamps)
1. **0:00–0:02 — Hook:** Start on the helicopter already approaching the truck. On-screen text: LANDING A HELICOPTER ON A MOVING TRUCK?!
2. **0:02–0:06 — Establish the challenge:** Show the truck moving and the helicopter lining up. Text: ONE SHOT. NO ROOM FOR ERROR.
3. **0:06–0:13 — Build tension:** Keep the approach continuous. Use a subtle speed ramp only if it does not hide the actual stunt.
4. **0:13–0:18 — Payoff:** Show touchdown and whether the helicopter stays on the truck. Add a brief slow-motion replay only if the original footage contains a clean landing.
5. **Final 1–2 sec — Loop / comment prompt:** WOULD YOU TRY THIS? End on a frame that can cut smoothly back to the opening.

## Voice-over (English)
> Okay, this truck is MOVING… and I'm trying to land a helicopter on it.
> The landing zone is tiny.
> Easy… easy…
> DID THAT ACTUALLY WORK?!
> Would you try this?

If the attempt fails, replace the final line with: I was so close… would you try again?
